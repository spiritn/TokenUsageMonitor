Token Monitor 0.1.0：将 Claude Code、Codex、WorkBuddy 与千问 Agent 的本地用量汇总到 macOS 菜单栏和网页。

- 免 API key、无遥测、默认只读本地日志。
- 原生面板、月份查询、零值日期、缓存可观测性与来源状态。
- 源码安装器、SHA-256 校验包、Homebrew 配方、启动/诊断/卸载命令。
- 图片全部使用合成数据。

此 Release 为源码分发，需要 Python 3.10+；原生面板还需 Xcode Command Line Tools。没有独立公证应用。Codex 分页历史、DeepSeek Harness 实用样本和 Apple Silicon 实机验证仍有限制，详见 README。
